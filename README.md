# Overview
A simple neural network demo program, operating on data with 21 inputs and a single yes/no output. The NN is represented as an object defined in the file. For initialization, the NN is given random values for the weights and bias, with a learning rate defined as a constant in the code (which can be changed for experimentation). Additionally, the NN object has a predicting method (to get a prediction for a particular input vector) and an adjusting method (for adjusting its own weights / bias for an input vector given the intended response). During runtime, the program will output the initial weights and bias, train the NN using the given data, display a result graph to the user (which can be zoomed into for further detail), and output the final weights and bias. When showing the weights and bias, the program will also display an accuracy percentage, showing how accurate the NN was at predicting the correct answer on the test data with its current settings.

# Data
The two data files are required in order for the program to function. They contain the necessary data for the NN to both train and test itself. As stated before, they are comprised of 21 inputs and a final numerical output. For the sake of the demo, we consider 3 a "no" and all other values a "yes". For those curious, the data used is data relating to patients with and without thyroid disease, and other medical conditions they have. Thus, we are effectively building a NN which is capable of predicting if a given patient has a thyroid disease.
